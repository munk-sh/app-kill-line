## ⚡ 什么是「App 斩杀线」？

在游戏里，**斩杀线（Kill Line）** 是指当 Boss 血量跌破某个阈值时，会被一刀直接带走。

过去十年，无数桌面与手机工具 App 明明只做了一点极其基础的本地功能，却敢收你 **$70 买断费、$9.99/月自动续费订阅、塞满开屏广告、甚至强行逼你登录云账号上传隐私文件**。它们以前能安心收租，并不是因为有什么技术壁垒，纯粹是因为没人愿意花几个月的人力去从零重写并长期维护一个免费版。

**现在，AI 直接把这条斩杀线拉高了。**

当一家由 Agent 驱动的 AI 软件公司，可以从零设计、编码、实机测试、Apple 公证签名并 24 小时维护一款本地优先（Local-First）的软件时——**所有复杂度低于这条线的「收租型」工具软件，都已经掉进了 AI 斩杀线。**

GitHub 上有很多 `open-alternatives` 仓库，但它们只是**整理别人链接的「书签导航」**；而本仓库是一家**真刀真枪下场造软件的「开源处决工厂」**：

1. **你点名，大家投票**：受够了某款又贵又难用的商业软件？直接[提交提名 Issue](https://github.com/munk-sh/app-kill-line/issues/new/choose)，或者去[投票排行榜](https://github.com/munk-sh/app-kill-line/issues?q=is%3Aissue+is%3Aopen+label%3Anomination+sort%3Areactions-%2B1-desc)给别人提名的 Issue 一楼点 **`👍 (+1)`**。
2. **AI 公司下场重做**：基于 **[Munk AI](https://munk.sh)**（*Open Company 开放公司运行时——一家可以 Fork、由 Agent 运营的公司*），我们的 AI 团队从零写出干净、零广告、纯本地优先、MIT 协议的免费开源平替。
3. **绝不烂尾（Agent 每 15 分钟巡检 Issue）**：我们不做「发完帖就跑路」的周末玩具。每个开源出去的仓库都挂着长效运维闭环——**专属 Agent 每 15 分钟巡检一次 GitHub Issues**，自动复现修 Bug、补自动化门禁、评估新功能并打包发版。

> **🚧 关于 [Munk AI (`munk.sh`)](https://munk.sh) 的状态说明**：
> 驱动这座软件工厂的 **Munk AI** 运行时目前正处于**内测与架构升级阶段，尚未正式公开上线**（当前 `munk.sh` 官网展示的仍是几个月前的早期版本）。正式版上线后将原生支持 **macOS、Windows 与 Linux**。

## 🗳️ 如何投票与提名？

### 1. 给榜上目标投票（GitHub 原生投票）
1. 打开 **[实时斩杀榜（按 👍 排序）](https://github.com/munk-sh/app-kill-line/issues?q=is%3Aissue+is%3Aopen+label%3Anomination+sort%3Areactions-%2B1-desc)**。
2. 点进你最想看到的软件 Issue，在**一楼正文左下角点击 `👍` (+1) 表情**即可！（*请勿在评论区水“+1”，GitHub 只按一楼正文的 `👍` 表情数计票排序*）。

### 2. 提名一个新的付费软件
1. 点击 **[New Issue → 🎯 提名付费 App / Nominate a Paid App](https://github.com/munk-sh/app-kill-line/issues/new/choose)**。
2. 告诉我们的 AI 团队三件事：
   - **它是哪款真实商业软件 & 怎么收钱的**（哪道付费墙或槽点最让你忍无可忍？）；
   - **最核心的 20% 必做功能**（只要做好哪 3～5 个功能，你就会立刻卸载原版？）；
   - **真实测试样本或极限场景**（方便 Agent 直接写成自动化验收门禁）。
